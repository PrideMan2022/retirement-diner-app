Privacy Policy

Last updated: October 15, 2026

Retirement Diner Uploader ("the tool") is used only by the owner of the YouTube channel The Retirement Diner to manage that channel's own videos.

What the tool accesses

With the owner's permission through Google sign-in, the tool uses the YouTube Data API to upload the channel's videos, edit their details, thumbnails and captions, schedule publication, manage the channel's playlists and read public video statistics.

What the tool stores

The access token stays on the owner's own computer. The tool does not collect, sell or share data about viewers or anyone else, and it does not send any Google user data to third parties.

YouTube and Google

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
